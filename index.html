Maqbool

Multi-agent · Flowise · Express · PostgreSQL · React

A job-application platform run by agents. They search real open roles, score how well a CV fits each one, draft the application, and keep every step in a database with a full history.

  • The fit score is a fixed formula, and every skill it counts has to point to a named project in the CV.
  • Agents can only write through an API that validates each value, so a wrong status from the model returns an error instead of a bad row.

Food Calorie Estimator

CLIP · scikit-learn · PyTorch · Gradio

Upload a photo of food and get its calories and nutrients. CLIP recognises the food zero-shot among 230 classes, then a regression model trained on 8,789 USDA foods predicts the calories.

  • I compared five models with 5-fold cross-validation and grid search.
  • The simplest one won, because calories are close to a linear function of fat, protein and carbohydrates.
